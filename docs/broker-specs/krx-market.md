### 2.1 호가 단위 (X-U1) — 확인 기록 2026-10-08
**출처**: X6(유가증권, KRX 규정 사이트 호가 탭), X7(코스닥, KRX 규정 사이트). 두 페이지의 HTML을 직접 수신해 표 텍스트를 추출했다. 아래 표는 X6 원문 그대로이며, X7(코스닥 "주권가격 / 호가가격단위")은 7개 구간·단위가 X6와 동일하다.

**주권 (유가증권시장·코스닥시장 공통)**
| 가격대 (원문 표기) | 호가단위 | 최소 스프레드 비율 (X6 표기) |
|---|---|---|
| 2,000원 미만 | 1원 | 0.05% 이상 |
| 2,000원 이상 5,000원 미만 | 5원 | 0.1 ~ 0.25% |
| 5,000원 이상 20,000원 미만 | 10원 | 0.05 ~ 0.2% |
| 20,000원 이상 50,000원 미만 | 50원 | 0.1 ~ 0.25% |
| 50,000원 이상 200,000원 미만 | 100원 | 0.05 ~ 0.2% |
| 200,000원 이상 500,000원 미만 | 500원 | 0.1 ~ 0.25% |
| 500,000원 이상 | 1,000원 | 0.2% 이하 |

**ETF·ETN·ELW (X6 "ETF, ETN 및 ELW 단일 호가단위" 표)**
| 가격대 | ETF·ETN | ELW |
|---|---|---|
| 2,000원 미만 | 1원 | 5원 |
| 2,000원 이상 | 5원 | (원문 공란) |

- **경계 규칙**: 원문이 "N원 이상 ~ M원 미만"이므로 경계 가격은 **상위 구간**에 속한다. 예: 정확히 20,000원 → 50원, 2,000원 → 5원(주식·ETF·ETN 모두), 500,000원 → 1,000원.
- **유효 지정가**: 호가가격단위는 "가격대별로 호가할 수 있는 최소단위"(X6 정의). 따라서 지정가는 해당 가격대 호가단위의 배수여야 한다. 이는 정의에서 도출한 해석이며, 배수가 아닌 가격의 **거부 여부·거부 코드는 키움 모의 서버 PV 실측 필요**. 가격대 판정 기준은 주문 가격 자체로 해석(X7 "주권가격")하나 원문 조항 미확인.
- **시행일**: 주식 통합 표 2023-01-25 시행 (N1, N2 — 2차 출처. KRX 2022-11-01 「증권·파생상품시장 업무규정 시행세칙 개정안」, 2010-10 이후 첫 개편). ETF·ETN 2,000원 미만 1원은 2023-10-05 KRX 개정 예고(N3) 후 **2023-12-11 시행**(N4 KB증권 공지, 2차 출처; 언론 예고일 12-08/12-18과 불일치하므로 정확한 시행일은 **부분 확인**). 현재 적용 여부는 X6 현행 표로 확인되므로 시행일 불일치는 M1 구현에 영향 없음.
- **2024~2026 개정**: 웹 검색 범위에서 주식·ETF·ETN 호가단위의 추가 개정은 **발견되지 않음**(부재 증명 아님). 2026-08 언론은 단일종목 레버리지·인버스 ETF·ETN의 **매매수량단위** 1주→20주 변경을 보도했으나(호가단위 아님) 원문 미확인 → X-U6으로 분리.
- **NXT(넥스트레이드)**: 증권사 안내(N5)는 호가단위가 KRX와 동일하다고 기재. nextrade.co.kr 원문은 미확인. M1은 KRX만 사용(03 D-045)이므로 참고용.
- **키움**: 키움 공식 API 문서에서 호가단위 규칙·거부 코드를 확인하지 못함(개발자 포털 미열람). 모의 서버가 X6 표를 그대로 적용하는지 **PV 실측 필요**.
- **미확인으로 남는 것**: ① 시행세칙 조문 번호(law.krx.co.kr 접속 503) ② ETF·ETN 개정 정확 시행일 ③ NXT 원문 ④ 키움 모의 서버 적용·거부 코드 ⑤ ELW 2,000원 이상 단위(M1 범위 외).
