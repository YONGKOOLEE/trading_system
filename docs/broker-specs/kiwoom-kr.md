# 키움 REST API — 국내주식 (M1) 확인 기록

- 확인일: 2026-10-01 (에이전트, 공개 문서 열람만. 로그인·API 호출·계정 연결 없음)
- 대상: 국내주식 모의투자(PAPER). 실전(LIVE) 항목은 참고로만 기록한다.
