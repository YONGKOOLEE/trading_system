## 0. 이 문서의 범위
- **전략 성과**(백테스트)와 **실행 안전성**을 따로 평가한다. 성과가 좋아도 안전성 기준에 못 미치면 전환 불가로 판정한다 (CLAUDE.md §7 4단계).
- 매매전략은 아직 정하지 않았다(00-strategy). 그래서 백테스트는 **모든 전략에 적용할 틀**을 정하고, 전략별 기준 수치는 각 전략 문서와 `docs/strategies/<ID>/backtest-v<n>.md`에서 정한다.
- 실행 안전성 검증은 전략과 무관하게 지금 확정한다.
- 이 문서의 승인은 구현 승인이 아니다. 테스트 코드는 6단계에서 작성한다.
