## 0. 이 문서의 범위
- **전략 성과**(백테스트)와 **실행 안전성**을 따로 평가한다. 성과가 좋아도 안전성 기준에 못 미치면 전환 불가로 판정한다 (CLAUDE.md §7 4단계).
- 매매전략은 아직 정하지 않았다(00-strategy). 그래서 백테스트는 **모든 전략에 적용할 틀**을 정하고, 전략별 기준 수치는 각 전략 문서와 `docs/strategies/<ID>/backtest-v<n>.md`에서 정한다.
- 실행 안전성 검증은 전략과 무관하게 지금 확정한다.
- 이 문서의 승인은 구현 승인이 아니다. 테스트 코드는 6단계에서 작성한다.

## 4. PAPER 검증

### 4.1 PAPER-0 인프라 검증 (D-076)
- 검증용 전략: 정해진 소수 종목(▢개)에 1주 단위 시장가 진입·청산. 게이트·한도·정지는 실운영과 같다.
- 시작 조건: 모든 L1~L3 통과, 시작 점검(03 D-066) 통과, 사용자 확인 항목(K-U1 IP·단말기, X-U3 휴장일, U-06 비용·약관) 완료.
- 절차: PV-01~12를 아래 표대로 확인하고 결과를 `docs/broker-specs/kiwoom-kr.md`에 출처 "② 모의 실측, 일자"로 기록한다. 실측이 03 설계 가정과 다르면 CP를 낸다.
