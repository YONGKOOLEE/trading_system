## 6. 안전성 검토
| 항목 | 판단 |
|---|---|
| 사람 확인 대체 | K4는 원래 "사람 확인" 정지다. 원격 재개는 사람(허용 채팅 + 확인 코드)의 의사 + **명령 시점 대조의 완전 일치**(MATCH, 열린 항목 0건)일 때만이다. 불일치 해소 판단(EXTERNAL·APPLY_FILL 등)은 원격에 열지 않는다. 즉 원격으로 풀 수 있는 K4는 "브로커와 내부가 지금 일치하는" 경우뿐이다 |
| 낡은 판정으로 재개 | 정지 관리자가 조건 증거의 대조 ID를 확인한다(D-136·D-137). 처리기를 거치지 않거나 복구 판정이 돌지 않으면 거부된다(V-181 (c), V-182 (c)) — 배선 결함이 있어도 위험 쪽이 아니라 거부 쪽으로 실패 |
