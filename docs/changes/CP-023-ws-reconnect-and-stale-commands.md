## 3. 안전성 검토
- P-1: K5 발동 시점은 변하지 않는다(한도 도달 시). 재접속을 계속하는 것은 위험 확대 요청을 늘리지 않는다 — K5 중 위험 확대 거부, 위험 축소 요청 없음(01 §2.6 K5)은 그대로. 복구 후 해제는 기존 경로(RECONNECTED → 조회 대조 일치)만 쓴다(DP-35).
- P-2: 지난 `/kill`을 무시하는 것은 위험 축소 명령을 놓칠 수 있다는 뜻이다. 완화: 무시했다고 즉시 회신·감사 기록·긴급이 아닌 안내이므로 사용자가 다시 보내면 실행된다. 로컬 `kill` 도구는 영향이 없다. 시작 직전 2분 안의 명령은 실행한다.
- 주문 경로·게이트·한도 변경 없음.
