- 근거: [00-strategy.md](00-strategy.md) v0.3 §2.3, D-003·D-004 (approved, A-005). [CP-024] CAP-ORD-03a·03b·CAP-INS-05 행과 M2 열 설계 비고는 00 v0.5 draft §2.3·2-M2(CP-024, A-066 승인 CP. **00 v0.5 승인 전**) 기준
- 역할: 시장별 CAP 지원 상태의 원본. 전략 등록 검증(§2.13)은 이 목록을 기준으로 한다.
- 상태 값: 미지원 / 검증 중 / 지원. "지원"으로 바꿀 때는 근거 T-ID와 검증 항목을 적는다.
- CAP 정의 추가·변경은 CP(`docs/changes/`)로 한다. 지원 상태 갱신은 5단계 계획과 6단계 구현 완료 기록에 따른다.
- 최종 수정: 2026-10-05 (CP-024 반영 draft: CAP-ORD-03을 03a 정정·03b 취소로 나눈 행 추가, CAP-INS-05 크립토 현물 행 추가, M2 열에 설계 확정 사실을 괄호 비고로 기록. **M1 상태 값 변경 없음, M2 상태 값은 모두 "미지원" 유지**(구현 전). 이전: 2026-10-03 T-020까지 구현·오프라인 검증 반영: M1 일부 "검증 중". "지원"은 PAPER 검증 후 — 결정 대기 DP-24)
- M2 열 괄호 비고 = CP-024에서 정한 **설계**이며 지원 상태가 아니다. 상태 값은 괄호 앞 단어만 읽는다(`src/trading_system/config/capabilities.py`). M2 상태는 T-M2 작업 구현·검증 기록에 따라 "검증 중"·"지원"으로 바꾼다
- "검증 중" = 구현과 fake·합성 응답 시험은 통과, 실제 모의 환경 검증 전. 등록 검증에서 BACKTEST 대상만 허용(DP-1)
