## 3. 바뀌는 문장
- 03 D-047 "M1: … 없으면 '미접수 종결'" → "[CP-031 D-171] 없으면 **K3**(자동 미접수 종결 없음, M2 D-111과 같음)". 03 §4 "전부 없음 → 미접수 종결"·§5.3 "발견 / 미접수 확정 / K3" → "발견 / K3". D-092 "종료 조건은 시장별" → "종료 조건도 시장 공통(K3)".
- 01 §2.5: 결과 불명이 있을 때의 거부 규칙은 그대로이며, **해소는 조회 발견 또는 사람 확정뿐**(자동 미접수 종결 없음). §2.7 E-1 행 "K3"의 뜻을 "5회 미발견도 K3"로 명시. §2.9 K3는 종전대로 로컬 전용 재개, 결과 불명 확정은 로컬 전용(변경 없음, 확인 문장만). R-06 "해소 또는 K3" 그대로, M1 단서 추가.

## 5. 영향과 재검토
- **M1 PAPER-0 운영**: 결과 불명 발생 시 하루 매매가 막힐 수 있다(K3는 자동 재개 대상 아님 — CP-029 D-152 사람 확인 정지 목록에 K3 포함, 자동 운영은 알림만). 지금까지 결과 불명 발생 0건(07-paper-review §5). 적용은 구현 브랜치 병합 뒤 다음 실행부터.
- **승인 재검토**: A-029(03 v0.5 D-047 포함)·A-053(CP-022 대조 보류)은 종료 조건만 바뀌므로 보류·채택 규칙(DP-39)은 그대로. 02 ST-01의 UNKNOWN → NOT_ACCEPTED 전이는 "사람 확정" 경유로만 남는다(전이 자체는 유지, 자동 전이 경로 삭제) — 02 v0.8 draft 반영은 문서 승인 묶음 때.
- **검증**: V-41은 V-232로 대체(기존 시험은 기대값 변경 — 요구사항 변경 사유: A-084 2-1). V-40·V-42·V-125·V-126 회귀.
- **운영 절차**: pv-procedure §3.1 "결과 불명 알림(UNKNOWN·K3)이 떠 있는 동안 그 종목은 수동 주문하지 않는다"는 그대로 유효하며, K3 해소 절차(사람 확정 → 대조 → 재개)를 사용 설명서에 넣는다.
