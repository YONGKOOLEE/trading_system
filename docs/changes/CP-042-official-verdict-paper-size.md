# CP-042 — M2 공식 판정 규모: PAPER 축소판 + A-064 (CP-038 D-244 (5) 개정, E-5 프로필 지정)

- 버전: v0.1
- 상태: **approved (A-128 ②, 2026-10-19)** — 사용자가 결정(질문 "공식 판정 규모" → "PAPER 축소판 + A-064")을 먼저 하고, 이 문서는 그 결정의 기록이다. 새 결정 없음.
- 작성일: 2026-10-19 (세션 50) / 대상: CP-038 v0.2 D-244 (5), D-235 E-5 적용, `config/m2/limits.paper.toml`
- 인도 차수: M2만. M1 영향 없음.

## 1. 문제
- [사실] crypto-trend v3 일반 규모 파라미터(`config/strategies/crypto-trend-v3.toml`)로 운영 장중 엔진(T-068)을 돌리면 M2 PAPER 한도 A-064(L7 1회 100 USDT 등)에서 주문 10,364건이 모두 G7 거부 → 거래 0 (2026-10-19, 통합 integ/2026-10-19c, 2020~2025).
- [사실] CP-038 D-244 (5)는 LF-8 표본 실행을 "배포 전략과 같은 코드 버전·같은 파라미터 파일(일반 규모, PAPER 축소판 아님)"으로 정했다. 일반 규모를 돌릴 승인된 한도 프로필이 없다(E-5 — 미승인 프로필은 적격 불가).
- [사실] 진입·청산 시점은 크기와 무관 — PAPER 축소판(`crypto-trend-v3-paper.toml`) 재현 75건(2020~2025)이 전략실 재생과 분 단위로 같다.

## 2. 결정 (A-128 ②)
| D | 내용 |
|---|---|
| D-281 | M2 crypto-trend 공식 검증(6창·저빈도 LF-0~LF-7)과 LF-8 표본 실행은 **PAPER-1 배포 파라미터(축소판)**와 **M2 PAPER 한도 A-064**로 한다. CP-038 D-244 (5)의 "일반 규모(PAPER 축소판 아님)"를 이 문장으로 바꾼다. |
| D-282 | E-5 승인 한도 프로필 = 공식 판정 전용 파일 `config/m2/limits.verdict.toml` — 값은 `config/m2/limits.paper.toml`(A-064)과 같고 최상위 `profile = "m2-paper"`, `approved_by = "A-064"`(CP-034 D-196 형식)만 더함. 운영 PAPER 한도 파일은 바꾸지 않는다(설정 해시 불변). 두 파일 값 일치는 시험으로 확인. |
| D-283 | 일반 규모(LIVE) 한도 값은 이 CP에서 정하지 않는다 — LIVE 준비 때 사용자 결정. LIVE 첫 규모는 CP-038 D-239(일반의 50% 이하) 그대로. |

## 3. 한계 · 미확인
- 축소판은 1회 주문 금액이 작아 최소 주문 금액(5 USDT)·수량 내림 영향이 일반 규모와 다를 수 있다 — 판정표에 고지.
- 일반 규모 결과(전략실 재생 105건·+6,964%·MDD 33.5%)는 운영 엔진으로 재현하지 않았다(한도 프로필 없음).
