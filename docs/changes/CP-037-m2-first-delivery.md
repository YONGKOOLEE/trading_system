## 7. 안전 검토
- **LIVE 자동화 없음**(CLAUDE.md §4·§7): 감독·예약 작업은 M2 PAPER(테스트넷)만, 코드가 PAPER·M2·테스트넷 시작 일치 표가 아니면 아무것도 만들지 않고 종료(D-223·D-231·V-296). A-078 "PAPER 전용" 원칙의 M2판. LIVE 무인 운영은 별도 CP·승인 없이는 없다. 실전 주문 코드 작성(승인 3)·LIVE 실행(승인 4)은 D-233 목록 충족과 별개이며 사용자 주도.
- **주문 경로 하나**(§8-2): 주기 판정은 신호를 만드는 시점만 늘린다 — 신호 → (M2 주문 조건 훅, D-201 (5)) → 게이트 → 실행기 → `BinanceSpotAdapter` → 스트림·대조·기록 그대로. 감독은 주문하지 않고 K8 재개 요청만 운영 명령 표에 넣는다(판정은 정지 관리자).
- **전략은 신호만**(§8-1): 분봉은 판정 입력 스냅샷으로만 전달, 전략은 어댑터·네트워크·저장소를 부르지 않는다.
- **결과 불명**(§8-6): 재시작해도 결과 불명 의도는 해소 조회만, 같은 의도 재전송 0, 미해소면 K8 자동 재개 거부(01 §2.11-5) → K3·사람 확인.
- **자동 재전송 없음**(§8-7): 주문 변경 1회 전송(D-203) 그대로. 재시도가 있는 곳은 조회·재개 요청뿐이며 모두 최대 횟수·대기·종료 조건이 있다(klines 조회 D-113 범위, K8 재개 12회·10분 시한, 재시작 24시간 2회).
- **재시작 직후 주문 금지**(§8-9): 자동 재시작 run도 K8 → 시작 대조 → 복구 조건 → 재개. 대조 전 주문 0(V-298).
- **정지는 청산이 아님**(§8-8): 리셋·사망·재시작 상한 어디서도 자동 청산 없음. 사람 확인 정지는 자동 해제 없음(D-226·D-228).
- **불확실하면 주문하지 않음**(§8-10): 닫힌 봉 누락·결측·품질 위반 → 신호 무효, 시계·스트림·규칙 이상 → 재개 거부.
- **모드·환경 분리**(§7): 테스트넷 호스트만, M2 체크아웃 `var/paper/`, M2 전용 봇. 공개 실서버 시세 수집(A-110)은 별도 스크립트·키 없음·주문 경로 없음 — run·감독 경로와 섞지 않는다(D-221은 로컬 파일만 읽음).
- **M1 영향**: 엔진 주기 일정(T-052)은 M1 실행 코드 → M1 프로파일 CAP-TRG-02 미개방, V-152 전체 회귀, 병합은 15:45 뒤 사용자 지시(D-218). M1 자동 운영 일정·예약 작업 불변(V-302).
- **위험이 늘어나는 곳**: (1) 무인 시간이 길어져 이상 상태가 사람에게 늦게 보임 → 긴급 알림·일일 요약·재시작 상한. (2) 자동 재시작(Q-2 (나))은 반복 장애를 일부 가림 → 24시간 2회 상한·사유 기록·사람 확인 정지 시 재시작 안 함. (3) 감독 자신이 죽거나 로그온이 안 되면 알릴 주체가 없음 → 일일 요약 부재로만 감지(남은 위험, §8). (4) 판정 횟수 증가로 호출량·거부 기록 증가 → 예산 시작 검사·판정 생성 주문 창 한정.
