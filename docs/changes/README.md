# 변경 제안

승인된 문서의 변경을 여러 문서에 걸쳐 제안할 때 `CP-<번호>-<요약>.md`로 작성한다.
포함할 것: 대상 문서·버전, 변경 문단·표 행, 영향 R/D/T-ID, 재검토가 필요한 승인·검증 항목.
업무정의서 v0.4의 CP-01~CP-10은 문서 안의 변경 요약 표에 있다. CP-011~CP-015는 03·04 문서 안 표에, CP-016 이후는 이 폴더에 둔다.
CP 승인은 CP 자체의 승인이며, 대상 문서(00~05 draft)의 `[CP-xxx]` 표시 반영은 문서 묶음 승인 때 기준본이 된다.
