- **전략은 신호만**(§8-1): `SymbolRules`는 읽기 전용 domain 자료형으로만 전달, 거래소 호출은 시스템.
- **주문 경로 하나**(§8-2): 이 CP는 주문 경로를 바꾸지 않는다. 지급 ETH 매도(Q-5 (나)·(다))는 기존 운영 요청 /exit → 게이트 → 실행기 경로, 테스트넷 주문 승인 범위 안에서만.
- **동시성**(§8-4): 여러 심볼 백테스트는 실운영과 같은 순차 게이트·예약으로 합산 한도를 검사(V-344). 실운영 처리 순서 [미확인]은 T-068에서 확인.
- **재시작 직후 주문 금지**(§8-9): 유니버스 변경은 정지 중에만, 시작 뒤 K8 → 대조 MATCH → 사용자 재개. `universe-add`는 K4를 풀지 않는다.
- **기준선·PAPER 기간 보존**: `universe-add`는 USDT 기준선·기존 소유권·PAPER 기간을 바꾸지 않는다(D-273 (4)) — m2-verify PAPER-0 기록 연속성.
- **룩어헤드**(V-91): 일봉은 실운영 함수 `final_daily_bars`로 거르고 미래 봉 교란 시험(V-345).
- **위험이 늘어나는 곳**: (1) 수동 보유 ETH가 L4·L3·L6에 들어감 → PAPER-0 K2 가능성(Q-5로 처리). (2) 두 심볼 상관 하락 시 K2 빈도 증가(D-274 (4)). (3) 호출 예산 2배(시작 검사가 이미 심볼 수로 검사, P-5). (4) 저빈도 90일 PAPER로 LIVE 판단이 늦어짐 — 안전 쪽.
