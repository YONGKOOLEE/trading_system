# CP-033 — 비시세 데이터 1차: 외국인·기관 일별 순매수 (CAP-DAT-05a) + 재무 스냅샷 축적

- 상태: **승인 A-100 (2026-10-14)** — Q-6 (a)·Q-7 채택·Q-8 (b). (작성 2026-10-11, 에이전트. 질문 단계 결정은 A-088(Q-1~Q-5 권장값).) 구현 T-035~T-037은 작업 지시 때.
- 근거: 사용자 "전략실 다음 단계 조사"(2026-10-11) → 조사 [broker-specs/kiwoom-kr.md](../broker-specs/kiwoom-kr.md) "비시세 데이터 조사 — CAP-DAT-05 후보" 절(S2 명세 2026-10-11, 파일 커밋 `6964258`; S3 2026-10-11), K-U42. 결정 A-088.
- 목적: 전략실이 수급(외국인·기관 순매수) 기반 아이디어를 **룩어헤드 없이** 연구·백테스트하고, 필요하면 같은 규칙으로 PAPER 판정에 쓸 수 있게 한다. 재무 값은 과거 조회가 불가능하므로 지금부터 쌓는다.
- 범위: M1(키움 모의)만. 주문 경로(신호 → 게이트 → 실행기 → 어댑터 → 대조)는 바꾸지 않는다 — 새 데이터는 판정 입력일 뿐이다(CLAUDE.md §8-1·§8-2). 한도·시간 값 변경 없음.
- 범위 밖: 공시·실적 발표 일정(키움 국내 API에 없음 — 필요해질 때 외부 출처 별도 CP, A-088 Q-5), 재무 값의 판정 사용(과거 이력이 없어 검증 불가), 장중 투자자 추정치(ka10063·ka10064), M2·M3.
- 새 ID: D-187~D-194, V-257~V-266, T-034~T-037, CAP-DAT-05a·05b·05c. 관련 기존: 00 D-002·D-004·§2.2·§2.3, 01 R-22·G11, 02 ENT(시세 계열), 03 D-057·D-095·D-141~D-145·§6.7, 04 §2.2·V-91, CP-030 D-162~D-164, A-073 E(수집은 run 꺼진 뒤), A-087(수집 도구 허용 API 목록).

## 3. 바뀌는 규칙 (승인 후 반영)

- **04 §2.2**: 05a 백테스트 공급 규칙(일자 < d), V 행 추가.
- **05**: T-034~T-037.
- **capabilities.md**: CAP-DAT-05a M1 "미지원" → T-035·T-036 완료 시 "검증 중", PV(실측 수집 N거래일) 뒤 "지원". 05b "해당 없음(판정 입력 아님)", 05c "미지원".
- **broker-specs/kiwoom-kr.md**: K-U42 실측 결과(T-034).
