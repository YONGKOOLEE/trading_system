## 7. 영향과 재검토
- **주문 경로**: 바뀌지 않는다. 새 능력은 신호 입력(데이터·트리거)과 요청 종류(지정가·정정)를 늘릴 뿐 게이트·실행기·대조를 우회하지 않는다. 정정은 원주문 방향 규칙(01 D-015) 그대로.
- **M1 PAPER-0**: 단계 1 반영 전후 검증용 전략(시장가) 동작 불변(V-240). `krx.toml`이 생기면 시세 스냅샷(ENT-30)의 호가 단위 칸과 paper_review 슬리피지 틱 칸이 채워진다(D-141·D-145 — "호가 표 없으면 '-'"가 숫자로 바뀜, 의미 변화 없음).
- **백테스트**: `krx.toml`이 생기면 틱 방식 슬리피지·상·하한가 호가 맞춤이 실제 가격대별 단위로 바뀐다 → trend-sma v1 등 기존 정합성 백테스트 지문이 달라진다. CP-030 % 방식 공통 판정은 호가 맞춤 외 영향 없음. 기존 결과 파일은 그대로 두고, 다시 돌릴 때 새 지문을 기록(V-240).
- **재검토 대상 승인**: A-084 2-2(CAP-ORD-02 미지원)는 X-U1 확인으로 조건이 풀린 것이므로 단계 1 승인 시 함께 갱신. A-005(00 §2.3), A-029(01 v0.5 정정 행), A-011(03 §13 구조 — 새 모듈은 기존 하위 구조 안: `marketdata/`·`broker/kiwoom/`·`app/`) 영향 확인. CP-024 §3 미결(CAP-ORD-03 분리 판정)은 D-175로 해소 제안.
- **M2**: 영향 없음. M2 정정 미지원·취소 지원(CP-024 D-104), M2 지정가 규칙(IOC)은 그대로.
- **LIVE**: 모의와 실전의 호출 제한이 다르다(실전 조회 TR 초당 5회 vs 모의 TR당 1초 1회, E4). 호출 예산(D-178)은 실전 값으로 다시 계산해야 하며, LIVE 체크리스트 항목으로 남긴다. 이 CP는 LIVE 승인과 무관.
- **남은 위험**: (1) 봉 확정 보수 규칙(D-177)은 실제 `cntr_tm`이 끝 시각이면 신호가 한 봉 늦다 → 성과 과소 평가(안전 쪽). (2) 0B 장중 수신 빈도를 모르는 채로 3a를 PAPER에 넣으면 WS 부하가 기존 00 통보 처리에 영향을 줄 수 있다 → 3a는 판정 미사용·통계만으로 먼저 관찰. (3) 단타 전략은 키움 모의 체결 방식(K-U4)과 실전 차이가 커질 수 있다 → 04 §4.4 기록 대상.
