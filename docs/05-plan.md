## 0. 이 문서의 범위와 전제
- M1 구현 작업을 T-ID로 나누고, 작업마다 연결 R/D-ID, 선행 조건, 산출물, 정상·오류 검증(V 항목), 완료 기준, 필요한 권한·가상 데이터·확인 주체를 적는다.
- **이 문서의 승인은 구현 승인이 아니다.** 사용자가 "구현 시작"을 명시적으로 지시해야 T-000에 착수한다 (CLAUDE.md §3).
- **실전(LIVE) 주문 코드는 어떤 작업에도 포함하지 않는다.** 키움 어댑터는 모의 도메인만 쓰며, 실전 도메인 상수와 실전 주문 경로는 만들지 않는다 (승인 구조 3번 전).
- 기한과 인력이 확인되지 않았으므로 **날짜와 공수는 적지 않는다**.
- 작업 하나씩 수행한다: 연결 문서 확인 → 테스트 작성 → 실패 확인 → 최소 구현 → 관련·회귀 테스트 → 변경 파일·명령·결과·남은 위험 보고 → 커밋 정책에 따른 커밋 (implementation-guide).
