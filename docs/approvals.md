# 승인 기록

- 이 파일에는 **사용자가 명시적으로 승인한 내용만** 기록한다. 에이전트는 사용자가 대화에서 명시적으로 승인한 내용을 옮겨 적을 수 있으나, 승인을 추정해 행을 만들지 않는다.
