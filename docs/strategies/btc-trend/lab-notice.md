# 전략실 통지 — btc-trend v1 운영 검토 반영 (2026-10-18, A-114)

- F-1: 필요 능력 CAP-INS-01(국내 상장주식, M2 "해당 없음" → 등록 거부)을 CAP-INS-05(크립토 현물)로 바꿨다. 메타데이터만 바뀌었고 규칙·계산은 그대로다.
- F-2: 운영이 `validate_rules(params, lot_step, min_notional)`를 추가했다(A-114 ③). 고정 LOT_STEP이 거래소 LOT_SIZE stepSize와 다르면 시작을 거부한다. m2_verify와 서명이 같다(DP-54).
- F-3: 운영이 `validate_deploy(params, eval_times, *, market=None)`를 추가했다(A-114 ③). 판정 시각이 정확히 1개가 아니거나 시장이 M2가 아니면 거부한다.
- 전략실 원본에도 F-1~F-3을 반영해야 다음 인계 때 차이가 생기지 않는다. 운영 판정·수량·신호 논리는 바꾸지 않았다.
- C-2(거래 수 ≥ 100) 처리: B안으로 정했다. 저빈도 전략용 대체 증거 규칙을 CP로 미리 고정하며, 이 CP는 초안 작성 단계이고 아직 승인 전이다(A-114 ②).
- 전략과 매매 횟수는 사용자가 아직 검토 중이다. btc-trend v1은 확정이 아니며, 공식 판정은 확정 전략과 CP 승인 뒤에 적용한다.
