## 한계
- **일봉 근사**: 01:00 체결가 = 그날 00:00 시가 기준, 04:00 체결가 = 그날 23:59 종가 기준(실제 판정 시각 가격이 아님 — 분봉 미사용). 매도 체결가가 실제 04:00 가격과 크게 다를 수 있다. 실행 경로(주문·dust·한도) 검증용으로만 의미가 있고, PAPER 체결가와 비교하는 기준(04 §4.2 신호·체결 차이)으로 쓰기 어렵다.
- **거래 규칙 시점**: 2017~2025 전 기간에 2026-10-14 테스트넷 규칙을 적용했다. 과거 실서버의 tickSize·stepSize·최소 금액과 다를 수 있다(과거 규칙 이력 미확인).
- **데이터 출처 차이**: 2-M2.2는 "테스트넷 1d klines"를 기준으로 적었으나 이 실행은 A-110 실서버 공개 일봉을 썼다(테스트넷 이력 길이·품질 미확인 B-U4). 신호 일치율 비교(2-M2.2 마지막 행)는 이 데이터로 하지 않는다.
- **PAPER는 테스트넷**: 유동성·호가·체결 품질·수수료 적용(B-U10, PV-M2-07)이 실서버 시세와 다르다. 이 백테스트는 IOC 매수가 매일 체결된다고 보았으나(슬리피지 0.1% < 완충 0.5%), 테스트넷에서는 체결 0·부분 체결이 날 수 있다(PV-M2-03·PV-M2-11 관찰 대상).
- 수수료율 0.1%·슬리피지 0.1%는 자리 값/공통 기본값이다(2-M2.2 ▢ 사용자 결정 전). 거래소 수수료 자릿수 반올림 미반영.
- 생존편향: U-A 고정 목록 BTCUSDT 1개(2026-10 시점 선택) — 사후 선택 목록.
- 룩어헤드 교란 검사는 무보유 스냅샷 비교(V-91 flat)만 — M1 stateful 교란은 M2에 없음.
- 거래 중단일 처리(2018-02-08 봉 제외)는 위 04 §2.1 해석이며, 그날 00:00~00:28 사이 실제 거래가 있었음을 반영하지 않는다(01:00 판정 시점에는 거래 중단 — 체결 불가와 결과가 같음).
