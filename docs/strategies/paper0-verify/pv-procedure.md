## 3. 실행 (사용자)
0. (장 시작 전, **run을 켜기 전에만**) 시작 점검. run이 켜져 있으면 점검이 거부된다(하트비트 30초 이내) — 점검 끝의 토큰 폐기가 엔진 토큰을 무효화하기 때문:
   ```
   $env:TRADE_MODE='PAPER'; .venv\Scripts\python scripts\preflight.py
   ```
   결과에 `시계(SNTP): 오차 …초`가 나온다. 오차 1초 초과면 실패 → Windows 시간 동기화 후 재점검.
1. 장 시작 전(08:50 전후)에 실행한다. **실행 창 하나만** 쓰고 창을 닫지 않는다(두 번 실행 금지).
   ```
   $env:TRADE_MODE='PAPER'; $env:PYTHONPATH='src'; .venv\Scripts\python -m trading_system.app run
   ```
   WARNING·EMERGENCY 알림과 정지는 이 창에 `[시각 KST] 등급 Kx 문구`로 바로 보이고, `var\paper\logs\ops-YYYYMMDD.jsonl`에도 남는다.
2. 시작하면 재시작 안전 정지 **K8**이 걸린다(설계, CLAUDE.md §8-9). 다른 창(먼저 `cd`)에서 대조 결과를 확인한 뒤 재개:
   ```
   .venv\Scripts\python scripts\status.py --mode PAPER
   .venv\Scripts\python scripts\resume.py --mode PAPER K8
   .venv\Scripts\python scripts\status.py --mode PAPER
   ```
   **09:25까지** 재개하고, 마지막 `status`에서 "해제되지 않은 정지: 0건"과 최근 운영 명령의 RESUME 결과(DONE)를 확인한다. 09:30 판정 때 K8이 남아 있으면 매수가 나가지 않는다.
3. 09:30 매수 1주, 14:30 매도 1주가 나간다(게이트 통과 시). 진행 중 확인: `.venv\Scripts\python scripts\status.py --mode PAPER`
   (포지션·미체결 주문·당일 의도/체결 수·최근 명령/알림·하트비트·시계 점검·전략 상태가 나온다)
4. 멈추기: 긴급하면 `.venv\Scripts\python scripts\kill.py --mode PAPER`(신규 진입 차단, 청산 아님). 끝낼 때는 3.1절 종료 순서.
5. 매일 장 마감 후 **키움 앱(모의투자) 주문체결내역·잔고를 시스템 상태와 비교**해 다르면 알린다.
6. 장 마감 후 백업: `.venv\Scripts\python scripts\backup.py --mode PAPER`

### 3.1 운영 주의 (검토 RV-17)
- **14:30 전 확인(14:20 전후)**: `status`에서 해제되지 않은 정지를 본다. 매도(청산)를 막는 정지(K5 등)가 있으면 재개 조건을 확인하고 알린다. 매수 보유 상태로 장이 끝나지 않게 한다.
- **종료 순서**: 14:30 매도 체결을 `status`로 확인(보유 포지션 0건, 미체결 0건) → 실행 창에서 **Ctrl+C**. 창의 X로 닫지 않는다.
- **PC 설정**: 실행 중 절전·화면 잠금 후 절전·최대 절전을 끈다. Windows Update 자동 재시작을 실행 기간 밖으로 미룬다(사용 시간 설정 또는 업데이트 일시 중지). 절전 복귀는 시계 점프로 K8을 건다.
- **동시 실행 금지**: run 실행 중에 `preflight.py`를 실행하지 않는다. run은 창 하나만.
- **첫 체결 직후(1일차 09:30 매수 체결 뒤)**: 바로 `status`로 열린 대조 불일치·K4가 없는지 확인한다(K-U16 시뮬레이터 가정 확인). 있으면 실행을 멈추지 말고 `status` 출력과 함께 알린다.
- **RV-23 실측 (첫 왕복)**: [2026-10-04 A-054] 시스템이 예수금 조회(시작·대조 때) 값이 바뀔 때마다 `CASH_OBSERVED`로 자동 기록한다(entr·d1_entra·d2_entra·ord_alow_amt·pymn_alow_amt) → `paper-review` "예수금 관찰" 표. 사용자 기록은 필요 없다. 여유가 있으면 장 마감 후 키움 앱 예수금 화면 값 1회만 대조용으로 적는다.
- **실행 중 K8**(절전 복귀·시계 점프·엔진 단계 오류): 다음 대조(장중 1분 이내) 뒤 `status`에서 정지가 "재개 대기"로 바뀌면 `resume.py --mode PAPER K8`로 재개한다(DP-41, 2026-10-04 수정 — 이전에는 재시작이 필요했음). 장 밖이면 주기 대조가 없으므로 재시작한다.
- **장 마감 후 알림**: "장 마감 후 미체결 N건이 브로커에 남아 있음" WARNING이 나오면 키움 앱에서 해당 주문을 확인해 알린다(03 §6.4, DP-40). 키움은 마감 소멸을 "만료"로 표시하지 않으므로(PV-03 실측 전) 그날 미체결이 남았다면 마감 후 또는 다음 날 K4가 걸린다 — `reconcile-resolve`로 사람이 정리한다(시장가만 쓰는 PAPER-0에서는 드묾).
- **수동 주문 (CP-022 W-1)**: 시스템이 쓰는 모의 계좌에 키움 앱으로 직접 낸 주문은 외부 거래(E-6) → 대조에서 K4 → `reconcile-resolve`로 정리한다(PV-13 외에는 하지 않는다). 특히 **결과 불명 알림(UNKNOWN·K3)이 떠 있는 동안 그 종목은 수동 주문하지 않는다** — 같은 종목·방향·수량이면 시스템 주문으로 오인 채택될 수 있다.
- **기록 집계**: 매일 끝나면 `.venv\Scripts\python scripts\paper-review.py --mode PAPER` → `var/paper/review/` 결과를 함께 보낸다.
- **선택: watchdog** — 별도 창(먼저 `cd`)에서 `.venv\Scripts\python scripts\watchdog.py --mode PAPER`. 하트비트가 30초 넘게 멈추면 알림만 한다(자동 재시작 없음).

권장 기간: **3~5거래일**(PV-02 여러 거래일 주문번호, PV-11 토큰 갱신 관찰 포함).

#### 무인 운영 주의 (2026-10-05 무인 운영 위험 검토)
- **실행 창**: Windows Terminal에서 실행하거나, 기존 콘솔 창이면 속성에서 "빠른 편집 모드"를 끈다. 창 안을 클릭·드래그해 "선택" 상태가 되면 출력이 멈추고 프로그램 전체가 알림 없이 멈출 수 있다. 출발 전 창 제목에 "선택"이 없는지 본다(있으면 Esc).
- **휴대폰 확인 2회**: 09:35·14:35에 텔레그램 `/status`. 09:30 매수가 안 됐으면(보유 없음) 14:30 판정에서 매수가 나가 밤새 1주를 보유하게 된다(전략에 시각 조건 없음) → 원치 않으면 14:30 전에 `/kill`(K1, 신규 매수 차단. 다음 날 아침 로컬에서 `resume.py K1`, 또는 텔레그램 `/resume K1` → `/confirm 코드` — K1은 종전부터 원격 재개 가능).
- **원격으로 풀 수 없는 정지**: K3·K4·K5(스레드 종료)·K7·K8은 로컬에서만 재개한다(01 §2.9). 무인 중 걸리면 그날 남은 매매는 없고, 보유 중이면 모의 1주를 다음 날까지 보유한다 — 1일차 수용 위험.
  - [CP-026, T-022 병합 후 적용] K4·K8은 원격 재개가 가능해진다(§3.3). 단 **명령 시점에 새로 한 대조가 완전 일치**(MATCH, 열린 불일치 0건)일 때만 풀린다. 열린 불일치 항목의 해소(`reconcile-resolve`)는 여전히 PC에서만 하므로, 불일치가 자동 종결되지 않으면 원격으로 풀 수 없다. **실행기가 건 K4**(비정상 통보·종결 후 체결)와 K3·K5(스레드 종료)·K7은 계속 PC에서만 재개한다. 병합 전에는 위 문장대로 로컬에서만 재개한다.
- **실시간 연결이 5분 넘게 끊겨도**(재접속 10회 실패) K5·긴급 알림은 1회 나가고, 재접속은 60초 간격으로 계속된다(CP-023, 2026-10-05 수정). 다시 붙으면 대조 후 자동 해제.
- **저녁에 반드시 Ctrl+C로 종료**하고 매일 아침 "시간 동기화 → preflight → run"으로 새로 시작한다. 밤샘 실행(토큰 24시간 만료 PV-11, 시계 밀림)은 사람이 볼 수 있는 날 따로 검증한다.
- 꺼져 있는 동안 봇에 보낸 명령은 시작 때 실행되지 않고 "꺼져 있던 동안 보낸 명령" 안내만 온다(CP-023). 시작 2분 안의 명령은 실행된다.

  - `/review`: 조회만(확인 코드 없음) — 오늘 체결 건수·종목·방향·수량, 정지·KILL 파일·결과 불명·불일치 건수, 마지막 대조 결과·시각, 열린 불일치 유형. 계좌번호·금액은 나오지 않는다.
  - 원격으로 여전히 불가: K3·K5·K7 재개, 불일치 해소, 결과 불명 확정, KILL 파일 삭제.
  - 거부되면 그날은 퇴근 후 PC에서 `status` 확인 뒤 로컬 절차로 처리한다.
- 주의: 알림 전송이 3번 연속 실패하면 **K11**(신규 매수 차단), 전송이 다시 성공하면 자동 해제. 키를 넣지 않고 켜면 run이 시작을 거부한다(키움 접속 전).
